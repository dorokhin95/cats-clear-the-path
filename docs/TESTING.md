# Стратегия тестирования и контроль качества (Testing Document)

Данный документ определяет критерии качества, методики тестирования и чеклисты проверки для игры «Котики: путь свободен!».

---

## 1. Критерий готовности задачи (Definition of Done)

Функциональность считается завершённой **только при одновременном выполнении** всех условий:
1. Код реализован, читаем и строго типизирован.
2. Автоматические модульные тесты успешно проходят без ошибок.
3. Проект успешно компилируется и собирается командой `npm run build`.
4. В консоли браузера отсутствуют ошибки (zero console errors).
5. Документация в папке `docs/` актуализирована и соответствует фактическому коду.

---

## 2. Уровни автоматизированного тестирования

### 2.1. Модульные и интеграционные тесты
- **Фреймворк:** Vitest.
- **Текущее покрытие:** **17 тестовых наборов, 64 теста (100% passed)**.
- **Зоны покрытия:**
  - `Board.test.ts`: лучевая трассировка, изоляция котиков, мгновенное освобождение клетки `grid[y][x] === null` сразу после клика.
  - `GameCompletion.test.ts`: сквозная симуляция реального геймплея через тапы (`Game.processCellTap`) для уровней 1–10, проверка корректного срабатывания события победы `onLevelComplete` и таймера победы 500 мс.
  - `LevelSolver.test.ts`: 100% валидация уровней 1–10, детектирование дедлоков, проверка метрик сложности (`maxDependencyDepth`, `forcedPrefixLength`, `branchingFactor`, `initialMovesCount`).
  - `LevelGenerator.test.ts`: детерминированность генератора по сиду `v2:${levelId}`, соблюдение точного количества котиков, строгий контроль `maxInitialMoves` для `hard` и `expert`.
  - `ChapterRegistry.test.ts`: расчет глав (1 глава = 10 уровней), корректная навигация ◀/▶, подсчет звезд главы (макс 30) и процедурные главы 2+.
  - `GameRules.test.ts`: расчет жизней, таймер комбо (окно 4.5с), формула очков `calculatePerformanceBreakdown` (0–100) и распределение звезд.
  - `GameplayFlow.test.ts`: поведение подсказок, сброс подсветки при ходе, сквозная разблокировка уровней и отображение в `LevelSelect`.
  - `Platform.test.ts`: определение окружения (`PlatformManager`), изоляция `WebPlatformService`, `TelegramPlatformService`, `YandexPlatformService`.
  - `SaveService.test.ts`: чтение/запись профиля V2, автомиграция V1 → V2, дефолтные рекорды уровней, устойчивость к повреждению JSON-данных в `localStorage`.
  - `ScreenManager.test.ts`: монтирование, переключение экранов и управление модальными окнами, события смены экранов для скрытия холста.
  - `SettingsMenu.test.ts`: сквозная загрузка настроек из профиля, мгновенное сохранение через единый `onSettingsChanged`.
  - `Particles.test.ts`: частицы следов лапок и конфетти, поддержка `reducedMotion`.
  - `SoundSynthesizer.test.ts`: 8-нотный пентатонический мотив комбо, гармонические аккорды на 4/8 комбо, 4 чередующихся звука тапа котика.
  - `CatHouseScreen.test.ts`: корректный расчет майлстоунов предметов по `getHighestCompletedLevel()` (без off-by-one).
  - `CollectionAndHouse.test.ts`: покупка скинов, переключение активного котика, развитие домика.

### 2.2. Массовое стресс-тестирование генератора (Stress QA)
- Тест `StressTest.test.ts`: генерация 1 000 уровней подряд на всех 4-х сложностях (`easy`, `normal`, `hard`, `expert`).
- Результат: **1 000 / 1 000 уровней (100%)** имеют гарантированное решение по солверу, строго соблюдают `maxInitialMoves` и не содержат дедлоков. Время выполнения ~38 секунд.

## 3. Чеклист ручной проверки (Manual QA Checklist)

### 3.1. Управление, таймеры и геймплей
- [ ] Клик/тап по котику со свободным выходом: котик приседает, издает один из 4 звуков тапа, убегает за экран.
- [ ] Клик по пустому месту игрового поля: звуки тапа НЕ воспроизводятся.
- [ ] Таймер уровня стартует строго с **первого клика** по котику.
- [ ] Полоса комбо плавно затухает за 4.5 секунды; при таймауте комбо сбрасывается без штрафов.
- [ ] На экране победы отображается время, комбо, ошибки и балл 0–100.
- [ ] Ошибки корректно списывают жизни (сердечки) на уровнях 6+. На уровнях 1–5 жизни бесконечны.

### 3.2. Интерфейс, экраны и адаптивность
- [ ] Полноэкранные меню (Главное меню, Выбор уровней, Коллекция, Домик, Настройки) имеют сплошной фон; игровое поле не просвечивает снизу.
- [ ] Экран выбора уровней отображает ровно 10 карточек на главу, стрелки ◀/▶ листают главы, отображается `⭐ X / 30`.
- [ ] Мобильный экран (9:16) и десктоп (16:9): центрирование, отсутствие растяжений.
- [ ] Все кнопки имеют область нажатия не менее 44×44px.
- [ ] Безопасные отступы `safe-area-inset` корректно обрабатываются.

### 3.3. Платформы и интеграции
- [ ] **Web / GitHub Pages:** Полная автономность, отсутствие сетевых ошибок инициализации внешних SDK.
- [ ] **Telegram Mini App:** Нажатие аппаратной/системной кнопки «Назад» закрывает текущее открытое меню; тактильный отклик (haptics) работает при нажатии кнопок.
- [ ] **Настройки:** Изменение громкости звука/музыки, тумблеров вибро и reduced motion сохраняется сразу и восстанавливается при перезагрузке страницы.
