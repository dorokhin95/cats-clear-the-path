# Дизайн интерфейса и UX (UI & UX Document)

Данный документ регламентирует структуру экранов, типографику, цветовую схему, интерактивные состояния элементов и правила адаптивного дизайна для игры «Котики: путь свободен!».

---

## 1. Цветовая палитра

| Название роли | HEX-код | Применение |
| :--- | :--- | :--- |
| **Основной фон (Background)** | `#FFF7E8` | Тёплый молочно-кремовый фон экранов и приложения |
| **Основной зеленый (Primary Green)** | `#62C98C` | Кнопка «Играть/Продолжить», состояние успеха, победа |
| **Акцентный оранжевый (Accent Orange)**| `#FFB84D` | Монеты, комбо, акцентные бейджи, звёзды |
| **Дополнительный голубой (Secondary Blue)**| `#63B7FF` | Вспомогательные кнопки, карточки скинов, подсказка |
| **Тёмный текст (Dark Neutral)** | `#363636` | Основной читаемый текст, подписи, иконки |
| **Цвет ошибки (Error Soft Red)** | `#F06A6A` | Потеря жизни, предупреждения (мягкий красный, не ядовитый) |

> **Правило:** Запрещается использовать чистый красный `#FF0000`. Ошибки должны выглядеть дружелюбно и мягко.

## 2. Типографика

- **Основной шрифт:** `Rubik` (локально включённый webfont).
- **Поддержка:** Русская кириллица и английская латиница.
- **Иерархия размеров (с адаптивным масштабированием):**
  - **Крупный заголовок (Header H1):** `42–56px`, жирный (font-weight: 700–800).
  - **Заголовок экранов/модалок (Header H2):** `28–36px`, жирный (font-weight: 700).
  - **Кнопки действий (Buttons):** `22–28px`, полужирный (font-weight: 600).
  - **Элементы HUD / Текст:** `18–22px`, средний (font-weight: 500).
  - **Вспомогательные подписи (Captions):** `14–16px`, регулярный (font-weight: 400).

---

## 3. Кнопки и интерактивные состояния

1. **Геометрия:**
   - Закругление углов (border-radius): `18–24px`.
   - Мягкая нижняя 3D-тень (box-shadow): создает приятный тактильный эффект «нажимаемой подушечки».
   - Минимальная область касания (Touch Target): **не менее 44×44 CSS px**.
2. **Анимация клика/тапа:**
   - Нормальное состояние: `transform: scale(1.0)`.
   - Нажатое состояние (active): `transform: scale(0.96) translateY(2px)`.
   - Длительность возврата: `120 мс` с кривой `ease-out`.
3. **Состояния элементов:**
   - `Normal`: стандартный яркий цвет с тенью.
   - `Hover` (на десктопе): легкое осветление фона (`filter: brightness(1.05)`).
   - `Pressed`: сжатие scale(0.96) и смещение тени.
   - `Disabled`: приглушенный серый оттенок (`opacity: 0.5`, `pointer-events: none`).

## 4. Экраны приложения

### 4.1. Splash Screen
- Центрированный логотип с лапкой 🐾 и названием «КОТИКИ: ПУТЬ СВОБОДЕН!».
- Аккуратный минималистичный индикатор реальной загрузки ресурсов.
- Мгновенный переход (без искусственного удержания игрока).

### 4.2. Главное меню (Main Menu)
- **Верх:** Баланс монет `💰 125`.
- **Центр:** Маскот-котик с легкой idle-анимацией дыхания и моргания.
- **Главная кнопка:** Большая зелёная «ПРОДОЛЖИТЬ» (запускает последний актуальный уровень).
- **Второстепенная кнопка:** «ВЫБОР УРОВНЯ».
- **Нижний ряд иконок:**
  - 🏠 «Домик»
  - 🐾 «Коллекция»
  - ⚙ «Настройки»

### 4.3. Выбор уровня (Level Select — Система Глав)
- Архитектура разбиения по главам: **каждая глава строго содержит ровно 10 уровней**:
  - Глава 1: Квартира (Уровни 1–10)
  - Глава 2: Двор (Уровни 11–20)
  - Глава 3: Парк (Уровни 21–30)
  - Глава 4: Крыши (Уровни 31–40)
  - Глава 5: Набережная (Уровни 41–50)
  - Глава 6+: Процедурные просторы (генерируемые уровни)
- **Шапка экрана:**
  - Кнопка «Назад» 🔙.
  - Навигация между главами: стрелки `◀` и `▶`, заголовок текущей главы.
  - Счётчик прогресса звёзд главы: `⭐ X / 30`.
- **Сетка карточек уровней:**
  - Ровно 10 округлых карточек на экране (сетка `5×2`), адаптивная вплоть до ширины 320px.
  - Пройденный: номер уровня, заработанные звёзды (⭐⭐⭐) и значок лучшего времени.
  - Текущий открытый: акцентная рамка и иконка 🔓.
  - Заблокированный: приглушённая карточка с иконкой 🔒.
- При открытии экрана автоматически открывается глава с последним доступным уровнем игрока.

### 4.4. Экран игры (Gameplay HUD)
- **Верхняя строка:**
  - Слева: Кнопка паузы `⚙`.
  - По центру: Номер уровня («Уровень 12»).
  - Справа: Жизни (`❤️❤️❤️` на обычных уровнях или `∞` на обучающих 1–5).
- **Живой таймер:**
  - `⏱ 00:00.0` — запускается в момент **первого тапа** по котику (позволяет спокойно оценить поле перед стартом). Обновление троттлится до 100 мс для экономии ресурсов.
- **Динамическая полоса комбо:**
  - Появляется при совершении успешного хода.
  - Показывает бейдж с множителем `×2`, `×3` и плавно убывающую полоску таймера (окно 4.5 секунды).
- **Центральная зона:** Игровое поле на Canvas (центрированное, адаптивное).
- **Нижняя строка:**
  - Кнопка подсказки `💡 Подсказка (3)` со счетчиком доступных бесплатных подсказок.

### 4.5. Окно паузы (Pause Modal)
- Затемнение фона (`backdrop-filter: blur(4px)`).
- Заголовок: «ПАУЗА».
- Кнопки:
  - «Продолжить» (зеленая, акцентная)
  - «Заново» (перезапуск уровня)
  - «Настройки»
  - «Главное меню»

### 4.6. Экран победы (Win Modal)
- Задержка 500 мс после выхода последнего котика + праздничный салют конфетти 🎉.
- Заголовок: «УРОВЕНЬ ПРОЙДЕН!».
- Анимированное выпадение звёзд (от 1 до 3) со звуковыми фанфарами.
- Информационная сводка прохождения:
  - Время: `⏱ 00:14.2`
  - Серия комбо: `🔥 ×5`
  - Ошибки: `0`
  - Мастерство: `Очки: 92/100`
- Награда в монетах: `+20 🪙`.
- Кнопки: «Следующий уровень» (большая зеленая), «Главное меню» (🏠), «Заново» (🔄).
- (При наличии интеграции с рекламой: кнопка удвоения монет за просмотр ролика).

### 4.7. Экран поражения (Lose Modal)
- Заголовок: «ОЙ! КОТИКИ ЗАПУТАЛИСЬ».
- Милый грустящий котик.
- Кнопки: «Попробовать снова» и «В меню».
- На платформах с рекламой (Яндекс Игры): кнопка «+2 жизни за просмотр рекламы» (на Web / Telegram кнопка автоматически скрывается).

### 4.8. Экран настроек (Settings Modal)
- Слайдеры громкости: «Музыка» 🔊 и «Звуки» 🔊.
- Переключатель (Toggle): «Вибрация» (для поддерживаемых устройств и Telegram WebApp).
- Переключатель (Toggle): «Уменьшить анимации» (Reduced Motion — отключает динамические частицы и ускоряет анимации).
- Сквозная синхронизация: настройки загружаются из актуального профиля игрока и мгновенно сохраняются при изменении.
- Кнопка «Назад».

### 4.9. Изоляция холста и непрозрачность экранов
- Для исключения паразитного просвечивания поля котиков все полноэкранные окна (Главное меню, Выбор уровней, Коллекция, Домик, Настройки) имеют CSS-класс `.ui-screen--opaque` с плотным фоном `#FFF7E8`.
- При переходе в меню Canvas скрывается (`.canvas-layer.hidden`), а `Renderer.render()` пропускает кадры, не нагружая GPU и батарею устройства.

## 5. Адаптивность и безопасные зоны (Safe Area)

- Мобильный формат 9:16 — ключевой приоритет.
- Десктопный режим: игра центрируется по горизонтали и вертикали, сохраняя пропорции, интерфейс не растягивается на весь ультраширокий экран.
- Все экранные контейнеры используют отступы с переменными окружения:
  ```css
  padding-top: max(16px, env(safe-area-inset-top));
  padding-bottom: max(16px, env(safe-area-inset-bottom));
  padding-left: max(16px, env(safe-area-inset-left));
  padding-right: max(16px, env(safe-area-inset-right));
  ```
