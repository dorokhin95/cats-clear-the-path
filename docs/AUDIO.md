# Звуковая концепция и музыка (Audio Document)

Данный документ регламентирует аудио-дизайн, техническую реализацию на базе WebAudio API, систему звуковых каналов (микшер) и спецификации звуковых эффектов для игры «Котики: путь свободен!».

---

## 1. Философия звукового дизайна

- **Характер:** Уютный, мягкий, жизнерадостный, медитативный.
- **Ограничения:**
  - Никаких резких, громких, агрессивных аркадных пищалок или сирен.
  - Ошибка не должна наказывать слух игрока неприятным звуком зуммера.
  - Звуки успеха должны приносить тактильное акустическое удовольствие (ASMR-эффект).
  - Мяуканье котика воспроизводится **редко** (примерно в 10–15% случаев выхода), чтобы не вызывать слуховую усталость при быстрой игре.

---

## 2. Архитектура аудиосистемы (WebAudio API)

```
                       ┌─────────────────────────┐
                       │    AudioContext Master  │
                       │     (Volume: 0.0 - 1.0) │
                       └────────────┬────────────┘
                                    │
                       ┌────────────▼────────────┐
                       │  DynamicsCompressorNode │  <-- Защита от клиппинга и искажений
                       └────────────┬────────────┘
                                    │
                   ┌────────────────┴─────────────────┐
                   ▼                                   ▼
       ┌───────────────────────┐           ┌───────────────────────┐
       │      Music Channel    │           │       SFX Channel     │
       │   (Volume: 0.0 - 1.0) │           │   (Volume: 0.0 - 1.0) │
       └───────────┬───────────┘           └───────────┬───────────┘
                   │                                   │
          Фоновые мелодии                     Звуковые эффекты:
         (Меню / Игра / Дом)                (Клики, прыжки, монеты)
```

1. **Процедурный синтезатор (SoundSynthesizer):**
   - Все эффекты синтезируются программно с помощью встроенных осцилляторов (`OscillatorNode`), огибающих громкости (`GainNode`) и фильтров (`BiquadFilterNode`).
   - Преимущество: отсутствие задержек на загрузку аудиофайлов, нулевой вес бандла, 100% готовность к работе в оффлайн-режиме.
2. **Аудиомикшер и компрессор (AudioManager):**
   - На выходе мастер-шины установлен `DynamicsCompressorNode` (порог -12 dB, колено 30 dB, атака 3 мс, спад 250 мс), предотвращающий перегрузки при частых быстрых тапах и полифонии комбо.
   - Три независимых коэффициента усиления: Master, Music, SFX.
   - Значения сохраняются в настройках пользователя (`SaveService`).
   - При потере фокуса страницы или уходе во вкладку фоновый звук автоматически приглушается (`AudioContext.suspend()`).

## 3. Спецификация звуковых эффектов (SFX)

| ID звука | Описание звучания | Синтез / Параметры |
| :--- | :--- | :--- |
| `ui_click` | Мягкий тактильный щелчок кнопки | Короткий импульс 40 мс, синусоида 600 → 400 Гц |
| `ui_back` | Закрытие окна, шаг назад | Мягкий спадающий тон 350 → 220 Гц |
| `cat_select` | Тап по живому котику (строго по котику, исключая клики в пустоту) | 4 чередующиеся вариации: базовые частоты 480, 520, 560, 500 Гц с разной крутизной огибающей (звучит живо и не надоедает) |
| `cat_escape` | Успешный побег котика со свободного пути | Свист ускорения (whoosh) + мягкий всплеск (pop). Случайный питч ±4% |
| `cat_blocked` | Путь заблокирован (ошибка) | Мягкое озадаченное «мррп!» (двойная модуляция синуса 220 → 180 Гц) |
| `combo` | Повышение счетчика комбо | 8-нотный восходящий мотив мажорной пентатоники (C5–C6) без застревания на верхней ноте; циклический переход с октавным обогащением. На серии 4 и 8 воспроизводится мажорный трезвучный аккорд |
| `star` | Появление звезды на экране победы | Хрустальный перезвон (chime) высотой 1200 → 2400 Гц |
| `coin` | Начисление монетки | Звонкий металлический щелчок (двойной всплеск 987 Гц и 1318 Гц) |
| `level_complete`| Победа в уровне | Короткий триумфальный джингл на 1.5–2 секунды (пентатоника, маримба) |
| `level_failed` | Поражение (закончились жизни) | Мягкий сочувствующий нисходящий аккорд (без драматизма) |
| `hint` | Активация подсказки | Волна волшебного перелива (arpeggio 800–1600 Гц) |

## 4. Музыкальные темы

1. **Главное меню (Theme: "Cozy Whiskers"):**
   - **Темп:** 88 BPM.
   - **Инструменты:** Мягкая маримба, pizzicato-струнные, лёгкая перкуссия, колокольчики.
   - **Длительность петли:** 60 секунд с бесшовным зацикливанием.
2. **Игровой процесс (Theme: "Purrfect Path"):**
   - **Темп:** 104 BPM.
   - **Инструменты:** Ритмичная маримба, мягкий бас, приглушенные хлопки, свинг-грув.
   - **Ощущение:** Сосредоточенность и легкость, никакой паники или таймеров.
3. **Домик котиков (Theme: "Nap in the Sun"):**
   - **Темп:** 80 BPM.
   - **Инструменты:** Теплый эмбиент, акустические переливы, мурлыкающий фоновый тон.
