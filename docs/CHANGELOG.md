## [1.2.0] - 2026-09-16 (Визуализация скинов, заселение Домика и живой маскот)

### Добавлено
- **Полноценное заселение Домика котиков (`CatHouseScreen.ts`):**
  - Все купленные игроком котики (до 9 видов) одновременно заселяются в Домик и размещаются по уютным местам (ковёр, кресло, когтеточка, окошко, цветок, подушка, мисочка, клубок ниток).
  - Адаптивные координаты мест в процентах для корректного отображения на экранах любой ширины.
  - Интерактивное поглаживание любого котика по тапу: подпрыгивание с физикой, всплывающие сердечки ❤️ и мурлыкающий звуковой эффект.
  - Подписи имён под каждым котиком и золотая отметка «★ Любимец» для текущего выбранного скина.
  - Динамический счётчик `🐾 В домике живут: X из 9 котиков!`.
- **Графический рендеринг скинов и аксессуаров (`CatRenderer.ts`):**
  - Поддержка палитр и декоративных деталей для всех 9 скинов коллекции: Рыжик (полоски), Дымок, Снежок, Уголёк, Сиамчик (тёмная маска), Трёхцветка (пятна калико), Кот в шляпе (котелок с красной лентой), Кот-пират (треуголка с золотым символом и повязка на глазу), Космонавт (прозрачный шлем с бликом).
  - Метод `renderPreviewToCanvas(canvas, skinId)` для чистой векторной отрисовки котиков на любых HTML5 Canvas элементах.
- **Интерактивные карточки коллекции (`CollectionScreen.ts`):**
  - Замена статичных эмодзи на индивидуальные Canvas-превью скинов высокого разрешения.
  - Моментальное обновление статуса покупки, баланса монет и заселения в Домик.
- **Живой маскот в Главном меню (`MainMenu.ts`):**
  - Главное меню отображает Canvas-маскота текущего выбранного котика с бейджем имени и редкости.
  - Тап по маскоту вызывает анимацию подпрыгивания и мяуканья.
- **Отображение любимца на игровом поле (`LevelLoader.ts`):**
  - При запуске любого уровня ведущий котик (id: 1) автоматически принимает скин выбранного игроком любимца.

## [1.1.0] - 2026-09-16 (Кроссплатформенность, UX, Рекорды и Звуковой ремастеринг)

### Добавлено
- **Платформенная архитектура (`src/platform/`):**
  - Абстракция `PlatformService` и фабрика `PlatformManager`.
  - `WebPlatformService` — автономный режим для браузера и деплоя на GitHub Pages.
  - `TelegramPlatformService` — нативная интеграция Telegram Mini App: синхронизация системной кнопки BackButton с модальными окнами, тактильный отклик (HapticFeedback), адаптация Safe Area и Viewport stable height.
  - `YandexPlatformService` — изолированный адаптер с динамической инжекцией SDK Яндекс Игр при активации, поддержка fullscreen и rewarded рекламы с fallback.
  - Документация: `docs/PLATFORMS.md`, `docs/GITHUB_PAGES.md`, `docs/TELEGRAM_MINI_APP.md`.
  - CI/CD автоматизация: `.github/workflows/deploy-pages.yml` для автоматического деплоя на GitHub Pages.
- **Постраничная система глав (`ChapterRegistry.ts`, `LevelSelect.ts`):**
  - Каждая глава содержит строго по 10 карточек уровней (Глава 1: 1–10, Глава 2: 11–20 и т.д.).
  - Навигация стрелками `◀` и `▶`, счётчик звёзд главы `⭐ X / 30`.
  - Адаптивная сетка 5×2 с корректным масштабированием на экранах от 320px.
- **Таймеры, комбо и многофакторная система звёзд:**
  - Таймер прохождения уровня стартует строго с **первого тапа** по котику, исключая спешку при изучении поля.
  - Динамическое окно комбо длительностью **4.5 секунды** с анимированной полосой затухания в `GameplayHUD`. Мягкий сброс при таймауте без штрафа к рекорду `maxCombo`.
  - Расчет мастерства `calculatePerformanceBreakdown` (0–100 баллов): скорость (до 50), ошибки (до 30), комбо (до 20).
  - Пороги звёзд: 1⭐ гарантирована за победу, 2⭐ при балле ≥ 60, 3⭐ при балле ≥ 85.
  - Экран победы `WinScreen` дополнен отображением времени, серии комбо, числа ошибок и итогового скоринга.
- **Схема сохранений V2 и рекорды уровней (`SaveService.ts`, `PlayerProgress.ts`):**
  - Поддержка хранения `recordsPerLevel` (лучшее время, максимальный скоринг, рекордное комбо для каждого уровня).
  - Бесшовная автоматическая миграция профилей V1 → V2.
- **Звуковой ремастеринг (`SoundSynthesizer.ts`, `AudioManager.ts`):**
  - В мастер-шину встроен `DynamicsCompressorNode` для подавления клиппинга при быстром комбо.
  - Мотивы комбо переведены на 8-нотную пентатоническую последовательность с циклическим октавным обогащением и полифоническими аккордами на 4 и 8 шагах.
  - Добавлены 4 чередующиеся вариации звука выбора котика `playCatSelect` с разной частотой и огибающей.
  - Звук выбора котика воспроизводится строго при клике на живого котика (исключены щелчки при кликах в пустоту поля).

### Исправлено
- **Изоляция экранов и производительность Canvas:**
  - Добавлен класс `.ui-screen--opaque` с плотным фоном для всех меню.
  - Игровой холст Canvas скрывается (`.canvas-layer.hidden`), а метод `Renderer.render()` пропускает кадры во время нахождения игрока в меню.
- **Домик котиков (`CatHouseScreen.ts`):**
  - Устранена ошибка off-by-one: майлстоуны мебели и комнат теперь проверяются по максимальному **завершённому** уровню `getHighestCompletedLevel()`.
- **Настройки (`SettingsMenu.ts`):**
  - Настройки инициализируются актуальными сохраненными значениями, изменения сохраняются немедленно.
  - Полноценная поддержка `reducedMotion` (отключение частиц лапок и конфетти, мгновенный побег котиков).
  - Удален неработающий селектор языка.
- **Покрытие тестами:**
  - Расширено до **17 тестовых наборов, 64 теста** (100% passed).

## [0.3.0] - 2026-09-16 (Этап 3 — Ядро игры)

### Добавлено
- Реализована сущность котика `Cat.ts`:
  - Координаты `(x, y)`, направления взгляда (`up`, `down`, `left`, `right`), скины (`ginger`, `smoky`, `snowball`, `shadow`).
  - Состояния: `idle`, `squashing`, `escaping`, `bumping`, `escaped`.
  - Плавные анимации: idle-дыхание со случайным сдвигом фазы, моргание глаз, squash & stretch при рывке, побег с ускорением, bump-отскок с показом `!`.
- Реализована сетка игрового поля `Board.ts`:
  - Хранение объектов в матрице ячеек.
  - Лучевая проверка свободного пути котика до границы поля (`canCatEscape`) во всех 4 направлениях.
  - Метод мгновенного освобождения клетки (`releaseCell`) для разблокировки зависимых котиков.
  - Метод глубокого клонирования доски для симулятора и солвера (`clone`).
- Реализован свод правил `GameRules.ts`:
  - Управление жизнями (❤️❤️❤️ на обычных уровнях, ∞ на обучающих 1–5).
  - Счётчик комбо с повышением множителя при правильных ходах и сбросом при ошибке.
  - Расчёт звёзд (0 ошибок → ⭐⭐⭐, 1 ошибка → ⭐⭐, 2 ошибки → ⭐).
  - Расчёт монет (базовые 10 🪙 + бонус за звёзды до 10 🪙 + комбо-бонус до 5 🪙).
- Созданы визуальные модули отрисовки:
  - `CatRenderer.ts`: процедурная отрисовка милых векторных котиков (ушки, тело, глаза с бликами, ротик, румянец на щечках, тень, поворот в направлении взгляда).
  - `BoardRenderer.ts`: центрированная подложка поля, уютные плитки ячеек, привязка кликов мыши/тача к координатам сетки (`canvasToGrid`).
- Интегрирована игровая логика в `Game.ts`:
  - Обработка клика/тапа с проверкой свободного пути.
  - Запуск анимации побега или столкновения.
  - Детекция победы при очищении поля с паузой 500 мс.
  - Детекция поражения при исчерпании сердечек.
- Написаны модульные тесты: `tests/Board.test.ts` и `tests/GameRules.test.ts`. Все 10 тестов успешно пройдены.
- Сборка `npm run build` завершена без ошибок (общий JS бандл 29.59 КБ / 8.78 КБ gzip).

## [0.4.0] - 2026-09-16 (Этап 4 — Первые 10 уровней и LevelSolver)

### Добавлено
- Описана структура данных уровней `Level.ts` (`CatData`, `LevelData`).
- Сформированы вручную первые 10 уровней первой главы («Уютная квартира») в `src/game/levels/chapter1.ts`:
  - Уровни 1–2: 3×3, вводные очевидные решения (1–2 котика).
  - Уровни 3–5: 3×3 и 4×4, появление прямых и параллельных зависимостей (уступи дорогу, две дорожки).
  - Уровни 6–10: 4×4, подключение системы жизней ❤️❤️❤️, перекрёстки, замкнутые подозрения, сложные цепочки до 8 котиков.
- Реализован загрузчик уровней `LevelLoader.ts`:
  - Инстанцирование экземпляров `Board` и `Cat` из декларативных данных.
  - Получение общего количества доступных уровней.
- Реализован алгоритм автоматического решения `LevelSolver.ts`:
  - Поиск в глубину (DFS) с симуляцией ходов на клонированной доске.
  - Расчёт эталонной выигрышной цепочки ходов (`solutionPath`).
  - Быстрая валидация корректности раскладки (`validate`).
- Написаны модульные тесты `tests/LevelSolver.test.ts`:
  - Автоматически протестированы все 10 уровней — **100% уровней имеют гарантированное выигрышное решение**.
  - Проверена детекция тупиков и замкнутых циклов взаимной блокировки (дедлоков) — возвращает `isSolvable: false`.
- Точка входа `main.ts` обновлена: уровни последовательно сменяют друг друга при прохождении.
- Сборка `npm run build` успешна (вес бандла 32.75 КБ / 9.52 КБ gzip). Все 12 тестов пройдены.

  - Интеграция с Canvas и вычислением координат центров ячеек через `BoardRenderer.ts`.

  - `playClick`: тактильный спадающий щелчок кнопки.
  - `playCatSelect`: упругий чпок при тапе по котику.

  - `playLevelComplete`: уютный триумфальный победный джингл.
  - `playHint`: волшебный перелив арпеджио.
- Создан менеджер звука `AudioManager.ts`:
  - 3-канальный аудиомикшер: Master, Music, SFX с сохранением пропорций громкости.
  - Ленивая инициализация `AudioContext` по первому тапу (соответствие Autoplay Policy браузеров).
  - Автоматическая пауза и возобновление контекста при смене вкладок (`visibilitychange` / `blur` / `focus`).
  - Процедурный генератор фоновой музыки (мягкая маримба 100 BPM в C-dur пентатонике).
- Звуковая система связана с интерфейсом: слайдеры громкости в Настройках, клики по кнопкам, анимация звёзд на экране победы.
- Написаны модульные тесты `tests/Particles.test.ts` (пулинг, жизненный цикл, очистка).
- Все 19 тестов в 6 файлах пройдены успешно. Сборка `npm run build` успешна (вес бандла 49.69 КБ / 13.25 КБ gzip).
