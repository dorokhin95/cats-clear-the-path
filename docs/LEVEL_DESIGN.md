# Дизайн уровней (Level Design Document)

Данный документ описывает структуру глав, кривую сложности, формат хранения данных уровней и спецификацию начальных 10 уровней для игры «Котики: путь свободен!».

---

## 1. Прогрессия сложности и Главы

| Глава | Название | Уровни | Сетка | Число котиков | Ключевой игровой паттерн |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Глава 1** | Уютная квартира | 1–15 | 3×3, 4×4 | 3–8 котиков | Обучение, прямые выходы, простые цепочки (A блокирует B) |
| **Глава 2** | Зелёный двор | 16–30 | 5×5 | 8–14 котиков | Разветвленные цепочки, выбор одного из нескольких первых ходов |
| **Глава 3** | Городской парк | 31–45 | 6×6 | 12–18 котиков | Глубокие цепочки зависимостей, перекрёстные пути |
| **Глава 4** | Тёплые крыши | 46–60 | 6×6, 7×7 | 15–22 котика | Сложные узлы, появление препятствий (коробки 📦) |

## 2. Кривая обучения (Onboarding)

- **Уровень 1 (3×3, 1 котик):** Котик смотрит прямо в край. На экране визуальная подсказка с пальцем. Игрок нажимает и сразу понимает смысл.
- **Уровень 2 (3×3, 2 котика):** Два независимых котика смотрят в противоположные стороны. Успех при нажатии на любого из них.
- **Уровень 3 (3×3, 2 котика, цепочка):** Котик А смотрит в котика Б. Котик Б смотрит в край. Если нажать на А — он отскакивает («мррп!»). Нужно сначала выпустить Б, затем А.
- **Уровень 4 (4×4, 3 котика):** Цепочка из трех котиков (C → B → A).
- **Уровень 5 (4×4, 4 котика):** Две независимые мини-цепочки. Разблокировка первого котика в Домике.
- **Уровни 1–5:** Режим без поражений (бесконечные сердечки).

```typescript
export interface CatLevelData {
  id: number;
  chapter: number;
  width: number;
  height: number;
  cats: {
    id: number;
    x: number;          // Позиция по X (0..width-1)
    y: number;          // Позиция по Y (0..height-1)
    direction: 'up' | 'down' | 'left' | 'right';

    x: number;
    y: number;
    type: 'box';        // Тип препятствия
  }[];
}
```

## 4. Спецификация первых 10 уровней (Handcrafted)

### Уровень 1: «Привет, котик!» (3×3)
- Сетка: 3×3. Котики: 1.
- `Cat 1`: (1, 1), `direction: "right"`. Путь вправо до края чист. Мордочка, ушки и глазки сразу видны игроку. Направляющая линия и баннер онбординга.

### Уровень 2: «В разные стороны» (3×3)
- Сетка: 3×3. Котики: 2.
- `Cat 1`: (0, 1), `direction: "left"`.
- `Cat 2`: (2, 1), `direction: "right"`.
- Оба могут выйти в любой последовательности.

### Уровень 3: «Уступи дорогу» (3×3)
- Сетка: 3×3. Котики: 2.
- `Cat 1`: (1, 1), `direction: "right"` (на пути стоит Cat 2).
- `Cat 2`: (2, 1), `direction: "up"`.
- Решение: сначала Cat 2 (наверх), затем Cat 1 (направо).

### Уровень 4: «Очередь за рыбкой» (4×4)
- Сетка: 4×4. Котики: 3.
- `Cat 1`: (1, 1), `direction: "down"` (заблокирован Cat 2).
- `Cat 2`: (1, 2), `direction: "right"` (заблокирован Cat 3).
- `Cat 3`: (2, 2), `direction: "right"` (свободен).
- Решение: 3 → 2 → 1.

### Уровень 5: «Две дорожки» (4×4)
- Сетка: 4×4. Котики: 4.
- Две параллельные цепочки по 2 котика на разных линиях.
- Завершение уровня открывает первого жильца в Домике котиков.

### Уровень 6: «Первый вызов» (4×4, включение жизней ❤️❤️❤️)
- Сетка: 4×4. Котики: 5.
- Глубина цепочки 4, ветвление 1.2.
- Требуется внимательность: случайный клик отнимает сердечко.

### Уровень 7: «Перекрёсток» (4×4)
- Сетка: 4×4. Котики: 6.
- Сбалансированный перекрёсток: начальная свобода ровно 2 хода (Cat 2 и Cat 4).
- `Cat 6` направлен вправо (упирается в Cat 1), глубина зависимости 4, ветвление 2.17.

### Уровень 8: «Уютная коробочка» (4×4)
- Сетка: 4×4. Котики: 6.
- Чистая цепочка зависимостей с depth = 6, forcedPrefixLength = 6.

### Уровень 9: «Лабиринт хвостиков» (4×4)
- Сетка: 4×4. Котики: 7.
- Глубокая цепочка с depth = 5, 3 начальных хода.

### Уровень 10: «Выпускной в квартире» (4×4)
- Сетка: 4×4. Котики: 8.
- Выразительный финал главы 1: 8 котиков, depth = 6, ветвление 2.0.

## 6. Бесконечная процедурная генерация (Уровни 11+)
- Начиная с уровня 11, игра бесшовно генерирует новые уровни процедурным генератором `LevelGenerator` с детерминированным сидом `v2:${levelId}`.
- Сложность плавно растет:
  - 11–15: `normal` (4×4, 7 котиков, maxInitialMoves: 2).
  - 16–25: `hard` (5×5, 11 котиков, maxInitialMoves: 2).
  - 26+: `expert` (6×6, 16 котиков, maxInitialMoves: 1).
- Все процедурные уровни гарантированно имеют 100% решение и сохраняют прогресс игрока без искусственных ограничений.
