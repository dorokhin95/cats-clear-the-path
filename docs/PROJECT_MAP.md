# Карта проекта (Project Map)

Данный документ описывает структуру репозитория, назначение директорий и каждого файла проекта «Котики: путь свободен!».

---

## 2. Назначение основных подсистем

| Подсистема | Папка | За что отвечает | Зависимости |
| :--- | :--- | :--- | :--- |
| **Game Core** | `src/game/` | Логика головоломки, правила, скоринг, таймеры, валидация | Не зависит от DOM/Canvas |
| **Rendering** | `src/rendering/` | Отрисовка поля, котиков и эффектов на Canvas | Читает данные из Game Core |
| **Audio** | `src/audio/` | Звуки, музыка, мастер-компрессор, синтезатор мотивов | WebAudio API |
| **UI** | `src/ui/` | Все кнопки, меню, окна и непрозрачный интерфейс | HTML/CSS DOM, ScreenManager |
| **Progression**| `src/progression/`| Сохранение звезд, рекордов, монет, коллекции | SaveService |
| **Platform** | `src/platform/` | Изоляция окружения (Web, Telegram, Yandex Games) | Браузерные и платформенные SDK |
| **Services** | `src/services/` | Сохранения V2, миграция, локализация, вибро | PlatformService, localStorage |
| **Locales** | `src/locales/` | Текстовые строки на русском и английском | LocalizationService |
