# Интеграция с платформой Яндекс Игры (Yandex Games Document)

Данный документ описывает требования и архитектурные правила интеграции с Yandex Games SDK.

---

## 1. Главные правила интеграции

1. **Последовательность разработки:** SDK подключается **строго после готовности рабочего оффлайн MVP**. Базовая игра должна идеально функционировать автономно.
2. **Безотказный Fallback:** Если SDK не загрузился (блокировщик рекламы, локальная разработка, другая платформа) — игра работает без сбоев через `localStorage` и локальные заглушки.

---

## 2. Монетизация и реклама

### 2.1. Межстраничная реклама (Interstitial)
- **Частота показа:** не чаще чем раз в 3–5 уровней.
- **Где показывать:** строго на экранах перехода между уровнями (после экрана победы перед загрузкой следующего уровня).
- **Запрещено:**
  - Показывать рекламу во время игрового процесса.
  - Показывать рекламу на первых 3–5 обучающих уровнях (игрок должен успеть полюбить игру).
  - Показывать рекламу при случайных кликах.

### 2.2. Реклама с вознаграждением (Rewarded Video)
- Полностью добровольная (вызывается только по явному желанию игрока).
- **Сценарии применения:**
  - `+2 жизни` при проигрыше для продолжения уровня.
  - Получение дополнительной подсказки (💡), когда закончились бесплатные.
  - Удвоение монет (`x2 🪙`) на экране победы.
- **Поведение звука:** При старте рекламы вызывается `AudioManager.muteAll()`, игра ставится на паузу. После закрытия рекламы звук восстанавливается в прежнее состояние.

---

## 3. Сохранения в облаке (Cloud Saves)

- Метод `ysdk.getPlayer().setData()` используется для синхронизации прогресса.
- При наличии интернета данные синхронизируются с облаком Яндекса.
- При отсутствии интернета сохранение производится в `localStorage`.
- В случае конфликта версий выбирается сохранение с максимальным значением `lastUnlockedLevel`.

---

## 4. Системные события и готовность (Game Ready)

- После завершения загрузки базовых ресурсов и скрытия SplashScreen вызывается:
  ```typescript
  if (window.ysdk?.features?.LoadingAPI?.ready) {
    window.ysdk.features.LoadingAPI.ready();
  }
  ```
- Игра автоматически останавливается на паузу при сворачивании вкладки или вызове системных оверлеев платформы.

---

## 5. Фактическая реализация (`YandexGamesService.ts`)

- **Класс:** `YandexGamesService` (`src/services/YandexGamesService.ts`).
- **Паттерн:** Singleton (`YandexGamesService.getInstance()`).
- **Скрипт:** `<script src="https://yandex.ru/games/sdk/v2"></script>` в `index.html`.
- **Типизация:** `src/types/yandex.d.ts`.
- **Методы:**
  - `init(): Promise<boolean>` — инициализация SDK и игрока (`getPlayer`).
  - `gameReady(): void` — сигнал готовности игры в `LoadingAPI.ready()`.
  - `showInterstitial(currentLevelId: number, onClose: (shown: boolean) => void)` — показ рекламы между уровнями с ограничением:
    - Не чаще чем раз в 60 секунд (`interstitialCooldownMs = 60000`).
    - Не показывать на уровнях 1–3 (`minLevelForAds = 4`).
    - Автоматическое глушение и восстановление звука (`audioManager.setMuted(true/false)`).
  - `showRewardedVideo(options)` — показ видео за вознаграждение:
    - Удвоение монет на экране победы (`WinScreen`).
    - +2 жизни при поражении для немедленного продолжения уровня (`LoseScreen`).
    - Дополнительная подсказка (💡) в `GameplayHUD`.
  - `saveToCloud(data)` и `loadFromCloud()` — облачная синхронизация прогресса с `ysdk.getPlayer().setData()`.
- **Fallback-режим:** Если игра запущена локально, без интернета или под AdBlock — SDK безопасно эмулирует работу без ошибок и исключений в консоли.
